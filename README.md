# 🚀 Node.js Telegram Bot + Express Server

## ⚡ About Project

This is a Node.js full-stack project where:
- Telegram bot runs
- Express server runs
- Simple landing page included
- Deploy ready (Render / Railway)

## 🔥 Features
- Telegram Echo Bot
- Express Web Server
- Static Website
- Health API (/health)
- .env support
- One command run

## 📁 Structure
/server.js
/bot.js
/public/index.html
/package.json
/.env.example

## ▶️ Run
npm install
npm start

## 🔐 ENV
BOT_TOKEN=your_token
PORT=3000
