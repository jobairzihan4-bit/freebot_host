# 📖 About

TeleGuard Render Bot Host is a simple deployment template for Telegram bots.

Instead of deploying only a bot, this template runs:

* 🌐 Express Web Server
* 🤖 Telegram Bot
* ⚡ Both in the same Node.js application

The website is intentionally lightweight while the Telegram bot starts automatically when the service starts.

# 🚀 Deploy on Render

## 1️⃣ Fork this Repository

Click the **Fork** button or **Use this template**.

---

## 2️⃣ Login to Render

https://render.com

Login using your GitHub account.

---

## 3️⃣ Create a Web Service

Dashboard

↓

New +

↓

Web Service

---

## 4️⃣ Select Repository

Choose your GitHub repository.

---

## 5️⃣ Build Settings

Build Command

```bash
npm install
```

Start Command

```bash
npm start
```

---

## 6️⃣ Add Environment Variables

Example

```env
BOT_TOKEN=YOUR_BOT_TOKEN
OWNER_ID=YOUR_TELEGRAM_ID
PORT=10000
```

---

## 7️⃣ Deploy

Click

**Deploy Web Service**

Wait until deployment finishes.
