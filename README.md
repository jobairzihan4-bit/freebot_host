# Node.js Express + Telegram Bot

A minimal, deploy-ready template running an Express web server and a Telegram bot in a single Node.js process.

## Features
- Serves a static HTML landing page via Express.
- Runs a Telegram bot (using `telegraf`) in the same application.
- Ready to deploy on Render, Railway, etc.

## Setup
1. `npm install`
2. Create `.env` from `.env.example` and set `BOT_TOKEN`
3. `npm start`
